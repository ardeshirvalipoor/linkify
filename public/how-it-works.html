A quick guide

From file to shared link.

Choose a file, set a few options, and share one link. No account or email attachment required.

Three simple steps

01 / Choose

Select a file up to 1 GB. You can drag it onto the upload area or browse for it.

02 / Set access

Choose an expiration time and, if you want, add a password check for the link.

03 / Share

When the upload completes, copy the link and send it to your recipient.

Frequently asked questions

How do I send large files?

Choose or drop a file up to 1 GB on the Linkify upload page. After the upload finishes, copy the generated link and share it with your recipient.

What if my upload gets interrupted?

Return in the same browser profile and choose the same file again within 7 days. Linkify can continue an upload while its saved browser data and the incomplete storage parts are still available.

Do I need an account?

No. You can upload and create a share link without signing up.

Can I add a password?

Yes. Turn on password protection before uploading and choose a password. It checks access to the file but does not encrypt the file, so share the password separately from the link.

How long does a share link last?

Choose one hour, one day, or one week. The countdown begins after the upload completes. Linkify stops accepting the share link at expiry; a storage URL already issued may remain usable for up to five minutes.

Can a link be used to download the file?

Yes. Anyone with the link can open it while it is valid. If you enabled password protection, they will also need the password.
